🎙️ Transcriptor en el navegador

Sube o arrastra un archivo de audio o vídeo y se transcribe aquí mismo, sin servidor. Funciona en varios idiomas.

📂 Arrastra un archivo aquí o pulsa para elegirlo

La primera vez se descarga el modelo (unos MB) y se guarda en caché para las siguientes. Todo ocurre en tu dispositivo: el audio no se sube a ningún sitio.

📝 Transcripción

¿Necesitas pegar directamente un enlace de YouTube? Eso requiere la versión con servidor (app.py), porque el navegador no puede descargar el audio de YouTube por sí solo.
